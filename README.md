Entry for the [make.fun bounty "Famous Last Words at 1 Percent"](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4): the funniest possible last words a phone would say when its battery hits 1 percent.

## The line

> Dying now, so here it is: your screen time is 11 hours a day, your password is your dog's name, and the Wi-Fi password dies with me.

132 characters, one line.

## How it works

`main.py` writes that single line to `/output/entry.txt` (UTF-8, 1–199 characters, no trailing newline), which is exactly what the bounty gate checks.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
